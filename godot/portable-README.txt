IMMUTABLE TOWERS - GODOT 4.7 PORTABLE

1. Extrai todo o conteudo do ZIP para uma pasta.
2. Mantem todos os ficheiros desta pasta juntos.
3. Abre run-game.bat ou ImmutableTowers.exe.
4. Nao e necessario instalar Haskell, Cabal ou Godot.

Os dados de contas e partidas ficam na pasta de dados da aplicacao do Windows,
separados desta distribuicao. Usa EXPORTAR CONTA no perfil para criares um
backup que pode ser restaurado noutro computador.
