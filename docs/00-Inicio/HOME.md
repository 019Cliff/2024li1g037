## Manutencao

Depois de alteracoes relevantes:

1. atualizar [[00-Inicio/estado-atual|Estado Atual]]
2. mover tarefas concluidas para [[02-Planeamento/extras-implementados|Extras Implementados]] ou para a nota do sistema
3. deixar [[02-Planeamento/backlog-jogo|Backlog]] apenas com trabalho aberto
4. registar validacoes em [[03-Qualidade-e-Release/changelog-jogavel|Changelog Jogavel]]
5. criar uma nova auditoria datada apenas quando houver nova evidência, não para guardar intenções
